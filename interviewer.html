Data Recovery

Recover exam data from candidates whose results were not saved to Supabase.

1

Send recovery tool to each candidate

Download the recovery tool file and send it to the candidate by email or WhatsApp. They open it in their browser and it automatically extracts and downloads their exam data.

Send recovery-tool.html to the candidate → they open it → a JSON file downloads → they send it back to you

2

Import the JSON file the candidate sends back

Once the candidate runs the recovery tool and sends you the JSON file, import it here to add them to your panel.

Accepts files from the recovery tool or any offline backup JSON

3

Advanced: Recover from Edge autofill database

If the candidate can't run the recovery tool, you can extract data directly from Edge's autofill database. Ask them to:

  1. Close Edge completely
  2. Press Windows + R → paste %LOCALAPPDATA%\Microsoft\Edge\User Data\Default → Enter
  3. Find file named Web Data (no extension) → copy to Desktop → send to you
